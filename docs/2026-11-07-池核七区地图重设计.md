# 池核七区地图重设计

计划文件：docs/2026-11-07-池核七区地图重设计.md
类型：详细 —— 理由：涉及地图数据、几何导出、Blender 烘焙、碰撞/水面和实机验收，跨多个子系统且工作量较大。

> 简述：把七区漫游从 24 个零碎房间改成一条以 28 m 长日光泳池为主景的池核环线，保留七个区域名和现有 UI，不碰剧情三幕；改完重建 roam 的 Blender 资产并做一次实机验收。

## 目标

重新设计七区漫游地图：以一个可读的日光长池大厅为核心，串联高窗柱廊、低顶水廊、静水泡池、滑梯浅池和冷光深井，形成 7 个可识别的池核区域和完整回路；最终直接落到 `npm run build` 可运行、实机可漫游的版本，不修改剧情三幕。

## 需求澄清

- 已问：范围 = 「不做剧情，把池核弄好」；交付 = 直接落到可运行版本；风格 = 日光长池 + 高窗柱阵。
- 假设：
  - 保留七个区域名（淋浴更衣室、主泳池、转角水道、静水泡池、滑梯浅池、光井冷水池、更衣休息廊）和现有 UI。
  - 保留 `/?preview=link` 北廊换翼小厅；新地图继续提供 `transfer` 房间和 `turnstile.ts` 的 `frames.roam` 位置，剧情三幕及其资产不动。
  - 保留现有滑梯交互（`slidePoints`/`slideLanding` 随新位置更新），不新增玩法。
  - 不新增怪物、jump scare、常驻任务 HUD；只做空间、水、光和材质。
- 待你拍板：
  - 是否接受把七区房间数从 24 个压缩到约 14–16 个（本计划默认接受）。
  - 是否要同步重生成 `art/map-atlas/poolrooms-atlas.blend` 总工程（默认重建 roam 的运行时资产，总工程在最后一步可选）。

## 现状

### 当前七区规模与结构

- `src/world/mapPlan.ts:25-133` 的 `roamPlan` 目前是 24 个房间、29 个开口、8 个水盆、6 条独立回路；房间碎、连接多，视觉上缺少一条明确的“长池主轴”。
- 现有七区 `views` 里 `gallery`、`return`、`sun` 等机位实际贴墙或被柱体遮挡（`mapPlan.ts:127-130`），`roam-2` 当前截图几乎全黑；说明“地图虽然能走通，但画面组织没有按池核构图设计”。
- 现有 `poolBasins.ts:6-7` 的 `poolSampleBounds`、`causticsBounds` 和 `roomPrograms.ts:13-16` 的 `slidePoints`/`slideLanding` 是按旧地图坐标硬编码的，改布局必须同步。
- `src/connection/turnstile.ts:4` 的 `frames.roam={x:21.25,z:4.3}` 和 `makeLobby()` 的偏移前厅是七区与剧情的换翼接口；新地图必须保留 `transfer` 房间或更新这个坐标。
- 现有 Blender 管线：`scripts/export-map-atlas.mjs` 从 `mapPlan` 生成 `art/map-atlas/<wing>/source.json`；`scripts/blender_current_scene.py` 逐翼执行 build/bake/export；`scripts/pack-map-atlas.mjs` 压缩 GLB —— 这条链已跑通，可沿用。

### 当前问题（来自本轮巡检）

- 主池大厅是“大而空”的平面房间，缺少长向水面、柱阵、窗光和视觉终点；墙地面材质修复后仍偏白，空间辨识度低。
- 入口到主池的视线组织弱：`roam-0` 平均亮度 12.4、89.2% 像素 <20；第一眼没有形成“从暗走廊进入亮水厅”的池核冲击。
- 七区的房间数量过多，单区特色被过道稀释；`roam-5` 右侧 1/3 被巨柱挡死，`roam-6` 画面被 transfer 外墙和门牌填满。
- 先前的材质修复已把 albedo/法线恢复（`AtlasMaterial.ts:29-48`），但地图本身没有给这些材质一个好的构图。

## 调研与审核

### 参考方向（只作为构图与空间参考，不复制资产）

- [Jared Pike / Dream Pools](https://www.jaredpike.art/projects/dream-pools/)：长向水池、前景粗柱遮挡、强日光、白色瓷砖、局部暗部；镜头通常是眼/腰高、24–35 mm。
- [Jared Pike 访谈（Scare Me!，2025-06）](https://scare-me.beehiiv.com/p/interview-artist-jared-pike-on-dream-pools-and-the-allure-of-liminal-spaces)：先定相机与灰模，再决定墙、柱、门洞；画面外可以完全不成立。
- [POOLS 官方网站](https://poolsthegame.com/) 与 [Dreamcore 官方网站](https://www.dreamcoregame.com/)：房间尺度反差、低顶连接、水路回环、声音随房间变化。
- [Backrooms Wiki · Level 37](https://backrooms-wiki.wikidot.com/level-37)：白色陶瓷砖、蓝绿温水、超出功能的尺度、异常光照与完全黑暗区域；社区词条，仅作设计参考。
- 本仓库 [`docs/POOLCORE_RESEARCH.md`](POOLCORE_RESEARCH.md) 与 [`docs/POOL_FIRST_PLAN.md`](POOL_FIRST_PLAN.md) 已记录同类结论：先构图后建模、统一浅色瓷砖、局部日光与可读暗部。

### 调研结论

1. 池核画面成立的关键不是房间数量，而是**一条长向水面 + 前景遮挡 + 远处未完全展示的转角**。
2. 七区应有一个 28 m 级别的主池大厅作为视觉锚点；其他区域是它的节奏变化：低顶水廊（压）、静水泡池（暖、低）、滑梯浅池（玩、亮）、冷光深井（垂直、冷）、休息廊（干、收）。
3. 地图上的房间数量应减少到约 14–16 个；每个房间至少承担“视线变化、路线变化、功能变化”中的一个，否则合并或删除。

### 审核结论

本计划按上述参考和仓库现状逐条核对：单区主景、长轴构图、低顶入口、回路、视线遮挡、水面/碰撞派生、Blender 重建、实机验收均有对应步骤；没有把“更多房间/更多装饰”当成质量指标。未发现需要追加外部调研的问题。

## 设计提案

### 总体蓝图

一条南北向主轴：**南侧低顶更衣入口 → 主池大厅（长池 + 高窗柱阵）→ 低顶水廊 → 冷光深井**；主池东西两侧各接一个侧区（西侧静水泡池、东侧滑梯浅池），并通过东侧休息廊回到入口，形成完整回路。

```text
                    ┌──────── 冷光深井（高 18m，深池）────────┐
                    │                                       │
                    │        低顶水廊（两次转折，2.3m）       │
                    │                                       │
  静水泡池 ◄───────┤       主池大厅（36×26m，高 16m）      ├───────► 滑梯浅池
  （暖光、低池）     │       28m 长池 / 东侧高窗 / 西侧柱阵   │        （浅水、滑梯）
                    └───────────────────┬───────────────────┘
                                        │
                              南侧低顶更衣入口
                                        │
                                  东侧休息廊 → 回到入口
```

### 区域与房间表（15 个房间、6 个水盆）

| 区域 | 房间 | 作用 | 关键尺寸/特征 |
| --- | --- | --- | --- |
| 01 淋浴更衣室（arrival） | `entry`、`rinse` | 低顶入口、更衣柜、冲淋、脚池；挡住主池全貌 | 2.2–2.35 m 顶；服务区地砖；一道偏置屏墙 |
| 02 主泳池（water） | `pool-hall` | 主视觉锚点：28 m 长池、东侧高窗、西侧柱阵、宽台阶入水 | 大厅约 36×26 m，顶 16 m；水面约 28×8 m，水深 2.4 m；可绕池一周 |
| 03 转角水道（gallery） | `north-neck`、`north-turn`、`north-lobby` | 低顶水廊，两次偏折，压低视线后进入深井 | 2.3–2.5 m 顶；水面 .04 m；错轴门洞 |
| 04 静水泡池（columns） | `warm-link`、`warm-hall` | 暖光、低矮、静水；石材池沿和抹灰气质 | 顶 5.2 m；水位 .55 m、干岸 .72 m；一个小天窗 |
| 05 滑梯浅池（rose） | `slide-hall` | 浅水、滑梯、启动平台；轻松尺度 | 顶 4 m；水深 .4 m；滑梯从 2 m 平台入水 |
| 06 光井冷水池（sun） | `cold-well` | 垂直奇观：18 m 高井、深池、偏置天窗、柱影 | 约 28×24 m，顶 18 m；池底 −6 m；高窗/井口 |
| 07 更衣休息廊（return） | `transfer`、`east-return`、`return-turn`、`rest`、`rest-link` | 干区回廊、柜体、木坐凳、水磨石；接回入口与北廊 | 2.5–2.8 m 顶；保持干燥；预留 `turnstile` 的 4.16×6.4 m 小厅 |

水盆：`main`（主池）、`north-channel`（北侧水廊）、`warm`（泡池）、`slide`（浅池）、`cold`（深井）、`rinse`（入口脚池）。其中 `north-channel` 贯穿 `north-neck`/`north-turn`/`north-lobby` 三段，做成连续浅水。

### 七个默认机位（`mapPlan.views`）

| 键 | 机位意图 | 画面要求 |
| --- | --- | --- |
| `arrival` | 更衣室屏墙后看主池门缝 | 暗前景 + 远处亮水，不直接暴露主池全貌 |
| `water` | 主池南端沿长轴看 | 28 m 水面占画面下半，东侧高窗光斑，西侧柱阵形成重复节奏 |
| `gallery` | 低顶水廊第一个转折处 | 前景低顶压住上方，远处门洞露出下一段水 |
| `columns` | 泡池入口看静水 | 暖色低顶、石材池沿，画面安静，无高光爆点 |
| `rose` | 滑梯池入口看滑梯与浅水 | 滑梯 S 曲线成为画面引导，水面浅、亮 |
| `sun` | 冷光深井岸边看井口/水面 | 垂直井壁与天窗形成上下构图，水面在下方 1/3 |
| `return` | 休息廊看回入口 | 木凳/柜体/水磨石，画面低对比、干区收束 |

### 不做什么

- 不修改 `hallPlan`、`arcadePlan`、`shaftPlan` 及 `src/story/**` 的剧情逻辑与剧情资产。
- 不加怪物、jump scare、任务列表、常驻 HUD、氧气条。
- 不把房间数量当作质量指标；优先保证主池一个“英雄视角”和一条可走回路。

5. **重新生成 roam 的 Blender 源与运行时资产** — 执行：
   ```powershell
   node scripts/export-map-atlas.mjs
   ```
