## 新地图

七区漫游当前为 15 个连通空间、15 个开口、6 个水盆，图论独立回路数为 1；七区名称继续用于暂停菜单，剧情三幕保持 18 个空间。具体房间、门洞和水域全部由 `src/world/mapPlan.ts` 的 `roamPlan` 定义。

1. 淋浴与储物入口：低顶、更衣柜、冲淋、脚池，偏置挡墙遮住主泳池全貌。
2. 主泳池：36 × 26 m、16 m 高大厅，约 28 × 8 m 长池；东侧高窗与西侧柱阵形成连续节奏，宽阶入水。
3. 转角水道：三段低顶水廊（2.3–2.5 m），两次错轴偏折后进入冷光深井。
4. 静水泡池：5.2 m 高、暖光、低水位的小厅，石材池沿和抹灰收口；从主池西侧经过短阶进入。
5. 滑梯浅池：4 m 高浅水厅，2 m 高启动平台和弯曲滑槽；水位较浅，适合作为轻快的尺度变化。
6. 光井冷水池：18 m 高大厅与深池，偏置天窗和柱影形成垂直奇观。
7. 服务与返回区：干区休息廊、柜体、木坐凳、水磨石，经东侧回廊接回入口与北廊换翼前室。

三幕的新结构：

- 日光厅：8 个空间、2 个水盆，2.15 m 入口经过错位挡墙进入 28 m 大厅；主池底 −3 m，15 级宽缓台阶；浅水侧廊形成完整回路并连接 12.6 m 高光井。
- 压力拱廊：9 个空间、2 个水盆，主轴总长 40 m；独立补水池、阀门岸道、间距递变的拱肋、低顶档案回环。三次重复后开放旧记录室的规则保留。
- 深井：圆井尺度保留，但重做圆形外壳、偏置岸台、入水宽阶、壁柱、顶部偏置采光口和滑道出口。回忆幕复用这套静态几何，剧情状态独立。

三个剧情空间与七区合计 33 个房间定义、11 个水盆。开口、池岸、地面高度、台阶和漫游视点都在 `src/world/mapPlan.ts`；碰撞、声学分区与水域从同一份数据派生。

## 几何与材质

- `compileMap.ts` 显式开门、切天窗、分割池底及台阶，不在运行时叠加整片地板。
- `solidSurface.ts` 删除内部面，并在材质和地面基准发生变化处停止贪心合并，防止服务区铺装延伸到邻室。
- 门洞为实际椭圆拱腹。平墙保持几何法线，曲面和小倒角保留平滑法线，避免门框周围的鼓包高光。
- 蓝色小砖池底、冷白墙砖、浅石材池岸、抹灰与服务区铺装共享区域 PBR 图集及法线/粗糙度图集。
- 12 mm 建筑倒角在 Blender 中完成；滑梯有 28 mm 壁厚。材质切换沿实际空间边界，不用重叠面遮缝。
- 删去水下解析回退里的旧扶手和旧曲墙，回退几何改读新池体；实际折射、反射和水波仍由 R3F 执行。
- 剧情道具从附近的 Cycles 烘焙样本取得低频照明；播放台补齐实体支撑。

## Blender 与运行时交付

可编辑总工程：`art/map-atlas/poolrooms-atlas.blend`，四个独立 Scene，贴图已打包。每个分区的工作文件在 `art/map-atlas/{roam,hall,arcade,shaft}/current-poolrooms.blend`。

总工程另含明确标记的水面预览集合，便于在 Blender 看池体关系。实时水、阀门动画、磁带摄像机、剧情门和检修管道仍由代码驱动；Blender 预览水不是浏览器水着色器的导出物。

烘焙使用 Cycles 128 samples、8 次漫反射、12 次总反弹。输出的是**每角点的低频照明**，不是继续放大旧 2048² EXR 光照图：采样边长上限 0.65 m，连接表面内做降噪，HDR 数值按平方根编码到顶点属性。太阳直射、阴影与水焦散在运行时计算，烘焙包含间接光与被建筑遮挡的天空直射。

这条路径避免旧光照图 UV 岛边界截断，但不是完整实时 GI：天空/太阳颜色和亮度会变化，间接光的空间分布是静态烘焙。它不能与任意时刻的离线路径追踪逐像素一致。

运行时资产：`src/world/assets/{roam,hall,arcade,shaft}.glb`，通过 Vite URL 导入；单文件离线包也会包含它们。Meshopt 压缩后四组模型约 8.24 MiB，不在行走过程中做 CSG 或生成全图。材质、顶点缓冲与反射裁剪变体沿用分帧预热；章节切换复用准备好的场景。

完整可复现顺序，在项目根目录的 PowerShell 执行：

```powershell
node scripts/export-map-atlas.mjs
foreach ($wing in @('roam','hall','arcade','shaft')) {
  $env:POOL_MAP_WING = $wing
  foreach ($stage in @('build','bake','export')) {
    & 'D:/blender/blender.exe' --background --factory-startup --python scripts/blender_current_scene.py -- $stage
    if ($LASTEXITCODE -ne 0) { throw "$wing / $stage failed" }
  }
}
Remove-Item Env:POOL_MAP_WING
node scripts/pack-map-atlas.mjs
& 'D:/blender/blender.exe' --background --factory-startup --python scripts/assemble-map-atlas.py
npm run build
```

`source.json` 指纹、`bake-report.json`、压缩清单及几何检查都保存在 `art/map-atlas/`。旧工程及本轮前源码保留；没有覆盖冻结的浴池参考。旧 `quietBath.json` 和旧烘焙脚本作为历史参考保留，不再拥有运行时建筑。
