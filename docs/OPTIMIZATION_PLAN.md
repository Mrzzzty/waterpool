## 目标

围绕“明亮但封闭，空旷却无法看清全貌”改造。以朴素、重复、用途不明的池室为主体，将原有梦幻彩窗保留在探索路径深处的特殊光厅中。重点强化熟悉建筑中的无人感、空间边界的不确定性与寂静。

## 1. 连通池室与环路

| 区域 | 空间设计 | 体验目的 |
| --- | --- | --- |
| 入口过渡室 | 低顶、浅色瓷砖、局部积水 | 建立熟悉而无人使用的感觉 |
| 宽阔浅水厅 | 大面积水面、较低天花板、少量粗柱 | 让空旷与封闭同时存在 |
| 错位柱廊 | 柱列不完全对齐，半墙挡住出口 | 无法一眼判断空间尽头 |
| 彩窗光厅 | 局部挑高，保留玫瑰窗与柔和彩光 | 形成探索过程中的视觉高潮 |
| 侧向回廊 | 窄门洞、转角、重复台阶 | 绕回浅水厅，产生似曾相识感 |

路线形成可辨认但不直白的环路。每个主要视角至少留一个被遮挡的入口，避免站在门口就看完整个房间。

## 2. 建筑与材质

- 小方砖连续覆盖墙面、粗柱、台阶与部分天花板，统一尺度。
- 减少金属饰边、柱头装饰和连续的教堂拱肋。
- 加入宽得异常的平台、偏离中心的门洞、用途不明的浅水凹室。
- 保持干净、完整的表面，通过建筑比例与重复感营造陌生感。
- 彩窗光厅保留精致细节，其余区域留出更多视觉空白。

## 3. 光照节奏

每个房间突出一个主要光源方向：高处窄窗、看不到外景的采光井，或转角后透进来的光。

明亮区域保留清晰瓷砖和柔和反射；门洞与远处角落逐渐变暗。降低全场均匀照明，让墙角、柱脚、顶棚接缝有明确的阴影层次。彩色投影集中在光厅附近，主体使用乳白、淡青与灰绿。封闭感不依赖整体变暗。

## 4. 水体与通路

- 让浅水绕过柱子、进入门洞，并覆盖部分台阶。
- 浅水区域允许涉水，移动速度略微降低。
- 干燥步道、浅水和深池具有清楚的高度区别。
- 波纹保持缓慢、小幅，焦散局部出现。
- 深池保留边界，避免进入未实现的游泳状态。

## 5. 交互、界面与声音

- 保留空格跳跃、重力与落地，以及按住右键 2× 放大、松开恢复。
- 地形变化时同步更新台阶高度、落地与碰撞。
- 进入漫游后，操作提示短暂显示再淡出；FPS 移入设置。
- 环境声默认关闭。开启后使用稀疏水声与随房间变化的回声：宽厅尾音更长，窄廊更短、更闷。

## 6. 实施顺序与性能

1. 完成五个区域的简化几何与通路，确认尺度、遮挡与环路。
2. 统一材质，处理明暗节奏和静态遮蔽。
3. 扩展水域、涉水、台阶与碰撞。
4. 调整声音与界面，完成性能分档。

复用现有 R3F 项目，将房间、门洞、水域和碰撞集中配置。重复建筑使用实例化，静态阴影与遮蔽尽量预计算。同一高度的水面共享渲染缓冲，限制实时反射数量，保留三档画质和自动降级。

60 FPS 为目标，需以实际设备测量为准。验证控制在一次类型检查和生产构建，加一轮短巡检，重点检查路线连通、跳跃落地、右键恢复和明显性能问题。浏览器验证以实际可用权限为前提。

已完成优先项：多房间环路、低顶浅水大厅、局部明亮与深处阴影的对照。

- 默认柔光关闭，移除白雾与发亮粒子；开口保留普通亮度的窗外背景，墙面及水体自身不发光。

## 晨昼暮时间流逝（2026-11-04）

按用户选择增加约 8 分钟一轮的晨光 → 白昼 → 黄昏 → 白昼 → 晨光平滑往返。太阳方向固定，色温与强度连续变化；全天球天空同步蓝色和晨夕暖色，云纹缓慢漂移。静态烘焙间接光调整强度/色调，动态水面实时捕获天空，低画质反射也同步时间颜色。

设置中加入“光阴流动”开关和“此刻的光”滑杆，显示阶段与百分比；拖动自动暂停，暂停同时停止云纹，后台页面不推进时间。没有引入完整昼夜或实时 GI 计算。类型检查与生产构建已通过。

最终定点预览确认白昼/黄昏的太阳色温、天空与水面反射同步变化；时间滑杆到 100% 时显示“黄昏 · 已停留”，光阴流动开关自动关闭。主厅白昼、主厅黄昏和走廊黄昏实图分别为 art/poolcore-sample/browser-daylight.png、browser-dusk.png、browser-gallery-dusk.png。截图为实际网页结果；未运行完整 8 分钟循环或性能压测。

## 分部位 PBR 贴图与法线（2026-11-04，当前实现）

针对“所有地方都是一种瓷砖”的反馈，新增五套原创程序化贴图并接入实际建筑：池底/水下墙面的青绿小马赛克、墙裙/栏墙的象牙釉面砖、上墙/顶棚/桥底的暖灰泥、台阶/池沿/压顶/拱圈的石灰岩，以及宽干区/步道的水磨石。原有 UI、几何、通行、太阳和晨昼暮循环保持原实现。

每套有颜色、OpenGL +Y 法线、粗糙度、16 位高度，以及运行时 normal-roughness 打包文件，共 25 张 PNG。大部分 1024²，灰泥 512²；贴图从同一份米制高度数据生成，砖缝/釉面/石材孔隙的法线和颜色对应。运行时只读 10 张贴图，共约 1.79 MiB；RGB 法线和 A 粗糙度共用一次细节采样，颜色用 sRGB，法线/粗糙度用线性空间。

沿用合并表面和实例化立柱，通过面片材质标记与世界坐标选择表面；墙裙依据房间基面分界。修复圆柱圆周 UV 插值问题，按整砖数环绕；切线基使用精确非零归一化，避免近看时法线凹凸被阈值压平。使用显式纹理梯度、mipmap 和最高 8× 各向异性过滤。没有新增逐砖模型或额外灯光，建筑仍没有自发光。
