## 水面实现

- [materials.ts](../src/scene/materials.ts)：折射颜色与深度使用匹配采样，排除水前物体；把视空间 Z 深度差换算为近似视线光程，再作吸收。根据相机空间法线扰动反射/折射，保留共享平面反射和 Fresnel。
- [PoolWater.tsx](../src/scene/PoolWater.tsx)：细化水面网格，重复边界顶点读取同一世界坐标的水深，让浅阶波幅过渡一致。仍为同水位水域共用一次场景/深度捕获和一个平面反射目标。
- [WaterCaustics.ts](../src/scene/WaterCaustics.ts)：将固定 0.9 m 接收平面替换为主池至第二池区域的世界空间焦散图。深度场来自实际地形；折射线用三次有界深度迭代估算命中，以面积变化近似聚光能量。高质量目标 512×1024、20 Hz，其他档位降低尺寸和更新频率。
- [liminalMaterials.ts](../src/scene/liminalMaterials.ts)：焦散调制接收到的直射光，受建筑阴影影响；间接光仅保留原有遮蔽。焦散在本轮覆盖区域外不再错误平铺。
- [poolWaves.ts](../src/scene/poolWaves.ts)：水面位移、法线与焦散共享同一波场；加入最多 8 个可复用的脚步涟漪槽。
- [FirstPersonRig.tsx](../src/scene/FirstPersonRig.tsx)：实际移动一定距离或入水时触发扰动，随水深降低移动速度，并平滑台阶上的视点变化。本轮为可涉水首段，不包含完整游泳控制。

借鉴了 Vackrooms 的池岸数据组织、扰动槽和折射深度方法，以及 Evan Wallace / ThreeJS Water 的面积聚光思路。采用当前 Three.js 0.180 / R3F 架构重新接入，没有迁移 WebGPU，也没有安装额外库。许可证及署名见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 2026-11-04：现有 WebGL 架构的视觉与光影完善

本轮保留 React / R3F / Three.js WebGL、UI、泳池布局、漫游和体力逻辑；优化光影、反射、池边材质与实用细节。

- `ContactShadows.tsx`：接入现有依赖中的 N8AO。采用 0.42 m 半径、0.65 强度、半分辨率和深度感知上采样，精致/均衡使用 12/8 个 AO 样本；流畅档关闭。线性输出交给现有 ACES 流程，禁用额外透明场景捕获。它是屏幕空间接触遮蔽，不能替代全局间接光，也不会为折射捕获内的池底额外计算 AO。
- `RoomReflections.tsx`：物品几何仍合批，但钢材、木条、涂层和玻璃钢按所在房间共享材质。房间反射使用 CubeCamera + PMREM，精致/均衡的立方体单面为 128/64；按距离与日照变化调度，捕获间隔至少 0.75 秒，流畅档停用。捕获时排除屏幕空间水面、体积光和反射物品，避免递归反馈。使用的是房间环境近似，不是逐像素光线追踪或视差校正反射。
- `causticsAtlas.ts` / `WaterCaustics.ts`：主池—水道—训练池、高水位泡池、静水池、滑梯浅池、冷水池和三个附属池使用 8 个独立区域。每区从当前地形/台阶生成深度场，保留三个实际水位。精致图集 1536×1536，均衡 768×768，流畅 384×384；按距离每次更新最多 2/1/1 区，频率为 20/15/10 Hz。未初始化区域保持中性，远区保留最近一次结果。水底焦散依旧调制接收到的直射光，不增加自发光。
- `liminalMaterials.ts`：池岸湿润度按真实池边距离和池岸高度渐变；补充低频颜色差异、轻微矿物水线和粗糙度变化。保留原法线强度与远处法线过滤。减少均匀半球补光，并让补光色温跟随原有晨昏周期。
- `poolDetails.ts` / `roomFixtures.ts`：泳池压顶分成约 1.2 m 的倒角石材段，保留细伸缩缝；其他水池的水下踏步加入齐平边线；训练池增加泳道底线；五个主要池体增加小型陶瓷回水口。没有新增楼层或水中大型装饰。
