# 池核\_开发计划

# 《池核 · 无水之夏》开发计划

> 在一座没有出口的室内泳池里，把「水位」当作钥匙，找回五个夏天的记忆。

- **主题**：池核（Poolcore）——白瓷砖、静水、无人、蓝绿色调、荧光灯下的潮湿空气
- **类型**：第一人称探索解谜（Walking Simulator + 空间谜题），无战斗、无 Jump Scare
- **技术栈**：three.js（WebGL2）+ 原生 ES Module，单文件可直接开玩，零外部美术/音频资源
- **单局时长**：12–18 分钟
- **交付物**：`/workspace/index.html`（可双击打开、可分享链接游玩）

---

## 一、为什么不是「又一个泳池步行模拟」

市面上的池核游戏（如 *Pools*、*Poolcore*）大多是纯氛围漫步：看水、听回声、走到底。氛围是够的，但**没有"玩"的理由**。

本作保留池核的全部视觉与情绪，同时给玩家一个只有这个题材才成立的机制：

> **水位就是钥匙。** 整座泳池共用一条水位线，涨水打开一条路，同时淹掉另一条路。

水的涨落同时改变**通行、呼吸、浮力、光影、声音**——这是别的题材给不了的解谜维度，也让"游泳"从移动方式变成思考方式。

**情绪设计**：恐惧不来自怪物，而来自"这里本该有人"。所有紧张感由水位上涨的声音、灯管闪烁、水下看不见的深处构成。

## 二、核心循环（30 秒讲清）

```
观察水位  →  找到泵房阀门  →  切换水位档  →  地形改变  →  取得记忆浮标
   ↑                                                          │
   └──────────────  每枚浮标给出一段独白与下一条线索  ←────────┘
```

- **三个水位档**：`0.0m（排空）/ 1.6m（半淹）/ 3.4m（满水）`
- **切换代价**：6 秒过渡动画（水声渐强、灯管频闪、水面上升），期间玩家可以观察空间变化
- **一局内至少完成一次完整水循环**：满水 → 排空 → 半淹 → 满水，形成节奏感

## 三、系统设计

| 系统 | 设计 | 玩家感受 |
| --- | --- | --- |
| 移动 | 走 / 跑 / 跳 / 攀梯 / 涉水（减速）/ 游泳 / 下潜 | 水的阻力让"走路"变成有重量的事 |
| 呼吸 | 水下氧气 45 秒，出水 3 秒回满；低氧时心跳与画面收缩 | 深水区成为真正的心理门槛 |
| 水位 | 全局单一变量，泵房三档切换，6s 平滑过渡 | 空间是可"操作"的，不是布景 |
| 交互 | `E` 阀门 / 拾取 / 读告示牌，准星高亮 | 极简，不打断沉浸 |
| 收集 | 5 枚"记忆浮标"，每枚绑定一个水位状态与一段夏日独白 | 收集物即叙事载体 |
| 威胁 | 无伤害。水下远处有缓慢移动的黑影，只在余光出现 | 不确定感 \> 惊吓 |
| 结算 | 5 枚集齐 → 天窗出口开启 → 白光 → 结束卡（用时/探索度） | 平静收尾，不庆祝 |

            │ 阀门中枢 │     │  出生点 L0  │   │  半淹     │

| 区域 | 作用 | 水位关系 |
| --- | --- | --- |
| 更衣室 / 淋浴间 | 出生点，教学（走、看、按 E），环境叙事（停摆的钟、褪色告示） | 干区；半淹时走廊可游泳进入 |
| 主池大厅 | 视觉中心，天窗光柱、跳台、回声 | 三档水位改变可游深度与光斑形态 |
| 跳水池（10m） | 纵向空间，深水恐惧来源 | 排空后沿铁梯下底；满水时从 10m 跳台跃入 |
| 儿童池 | 唯一"暖色"区域，怀旧感最强 | 半淹时水面浮台可借力跳上喷泉顶 |
| 泵房 B1 | 阀门中枢，机械噪音，唯一的"人工"空间 | 水位切换点，本身永远干燥 |
| 天窗平台 | 终局 | 仅满水时可从浮台够到 |

**五枚浮标的取法（强制一次完整水循环）**

| # | 位置 | 所需水位 | 谜题 |
| --- | --- | --- | --- |
| I | 主池池底 | 0.0m | 排空后跳下 3m，池底排水口旁 |
| II | 跳水池底 | 0.0m | 沿生锈铁梯下到 10m，全程无光，只有手电 |
| III | 更衣室走廊尽头 | 1.6m | 半淹，需潜水穿过倒塌的储物柜间隙 |
| IV | 儿童池喷泉顶 | 1.6m | 水面浮台被抬升，跳上去够到 |
| V | 天窗横梁 | 3.4m | 满水，游到浮台边缘起跳 |

## 五、技术方案

### 5.1 架构

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 渲染 | three.js r169 + WebGL2 | importmap 引 CDN，无构建步骤 |
| 后处理 | EffectComposer + UnrealBloom + 自定义 ShaderPass | 泛光、暗角、胶片颗粒、水下色差与轻微扰动 |
| 几何 | 程序化 Box/Plane 拼装 + `InstancedMesh` | 瓷砖柱、储物柜、淋浴头、池边栏杆复用实例 |
| 纹理 | Canvas2D 程序化生成 | 瓷砖（含勾缝/水渍/霉斑）、混凝土、锈铁、泳道线、告示牌 |
| 水体 | 自定义 `ShaderMaterial` | Fresnel 反射 + 程序化波法线 + 深度渐变 + 岸边泡沫带 |
| 水下 | 雾色切换 + 全屏 tint + 悬浮微粒 + 焦散投影 | 不做真实折射，靠色彩与光斑骗过眼睛 |
| 物理 | 手写 AABB + 玩家胶囊 | 分轴滑动碰撞、台阶 step-up、梯子吸附 |
| 音频 | WebAudio 全程序化 | 灯管嗡鸣、水拍岸、脚步、滴水、水下低通、心跳 |
| 状态 | 轻量状态机 + localStorage | 保存已收集浮标与画质设置 |

### 5.2 关键技术点

1. **水位驱动的世界**：一个 `waterLevel` 变量驱动水面高度、雾密度、环境光色、混响参数、以及若干部件的显隐/碰撞体开关（浮台、梯子、闸门）。所有"水位谜题"只读这一个变量，逻辑极简但表现丰富。
2. **水体着色**：顶点做少量波动，片元用 3 层不同频率的 sin 噪声扰动法线，按视线角度做 Fresnel 混合；深度用"水面到池底的距离"做青→墨绿渐变；池壁交界处叠一圈白色泡沫带。
3. **焦散**：一张程序化生成的流动焦散贴图，用加法混合贴在池底上方 1cm，随水位与时间偏移，比真实光子映射便宜两个数量级。
4. **游泳手感**：水中重力降为 15%，加入阻尼与"抬头出水"的镜头浮力；下潜时相机轻微滞后，制造水的黏滞感。
5. **性能预算**：\< 15 万三角面、\< 120 draw call、单盏投影灯、`pixelRatio` 上限 1.75，目标 1080p / 60fps 集显可跑。三档画质（高/中/低）可切。

### 5.3 兼容与降级

- CDN 加载失败 → 显示明确提示，并回退到备用 CDN（jsDelivr → unpkg）
- 后处理初始化失败 → 自动关闭 Bloom，仅用基础渲染
- 无 Pointer Lock（部分内嵌环境）→ 自动切换为"按住鼠标拖拽视角"
- 移动端 → 触屏摇杆 + 拖拽视角 + 交互按钮（第二优先级）

## 六、美术规格

**色板**

| 用途 | 色值 |
| --- | --- |
| 瓷砖（受光） | `#E6EFEA` |
| 瓷砖（阴影） | `#9FB6B4` |
| 池水（浅） | `#3FB3A6` |
| 池水（深） | `#0A3941` |
| 荧光灯 | `#FFF4DC` |
| 雾 | `#C3D5D2` |
| 锈迹 / 暖色点缀 | `#B4713E` / `#E8C36A` |

**光照**：整体低对比、高环境光（HemisphereLight 冷青 + 暖白），天窗一束体积光（用半透明锥体 + 噪波贴图伪造），泵房只有一盏摇晃的钨丝灯。灯管随机频闪（0.5–2s 随机间隔），是氛围的主要来源。

**材质**：所有瓷砖带轻微色差、勾缝发黑、局部水渍与霉斑——"干净但被时间泡过"。避免镜面感，粗糙度 0.55–0.85。

## 七、音频设计（全部合成，无版权风险）

| 声音 | 合成方式 |
| --- | --- |
| 空间底噪 | 两个失谐正弦 + 低通滤波，缓慢 LFO，模拟灯管与通风 |
| 水拍岸 | 白噪声 + 带通滤波 + 慢速包络，随机触发 |
| 脚步 | 短噪声脉冲 + 低通，湿区叠一层水花；不同地面不同滤波 |
| 滴水 | 正弦 ping + 长衰减 + 卷积混响，随机 3–9 秒 |
| 水下 | 主输出低通 500Hz + 轻微失真 + 心跳 |
| 水位变化 | 低频轰鸣渐强 + 水流噪声，与 6 秒过渡同步 |
| 混响 | 程序化生成脉冲响应（指数衰减噪声），大厅 3.2s / 泵房 0.6s |

> 没有音乐。只在结局给一段极简钢琴单音，作为情绪释放。

## 八、交互与 HUD

- `WASD` 移动 · `Shift` 跑 · `Space` 跳/上浮 · `Ctrl` 下潜 · `E` 交互 · `F` 手电 · `Esc` 暂停
- HUD 极简：左下角氧气条（仅水下出现）、右上角水位深度尺（像泳池边的水位标尺）、浮标计数
- 无小地图、无任务列表、无血条。方向感靠建筑本身（天窗光柱作为唯一地标）
- 首次进入 40 秒内完成"走路 → 看告示 → 按 E 开门"的教学，不弹窗

## 十、风险与对策

| 风险 | 对策 |
| --- | --- |
| 水体着色性能差 | 单张水面 + 屏幕空间近似，不做实时折射/反射探针 |
| 水下迷失方向 | 每个水域放置 1–2 个光柱/气泡源作为视觉锚点；HUD 水位尺辅助定位 |
| 玩家找不到泵房 | 出生点正对一条"水渍轨迹"通向泵房；告示牌用箭头暗示 |
| 晕动症 | 提供 FOV 滑杆、关闭镜头晃动、水下不加速 |
| CDN 不可用 | 双 CDN 回退 + 明确的加载失败提示 |
